# tables

This folder contains tabular outputs intended for interpretation and presentation.

## Subfolders

- `market_evaluation/`
- `season_report/`
- `next_matchday_predictions/`

## Difference from `data/processed`

`data/processed` is the analytical working layer of the project. `outputs/tables` is the presentation-oriented layer where tables are easier to read directly or export into the written thesis.
