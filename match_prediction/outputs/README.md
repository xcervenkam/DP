# outputs

This folder contains outputs intended for interpretation, reporting, and model reuse.

## Structure

- [`figures/`](figures/README.md)  
  Visual outputs for evaluation and seasonal reporting.

- [`tables/`](tables/README.md)  
  Tabular outputs suitable for interpretation or direct reuse in the written thesis.

- [`models/`](models/README.md)  
  Saved models and deployment artifacts.

## How to Use This Folder

- If you are looking for results to include in the thesis text, start with `figures` and `tables`.
- If you want to reuse trained models without retraining, go to `models/deployment`.
