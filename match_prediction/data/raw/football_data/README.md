# football_data

This folder contains Bundesliga odds data from Football-Data.co.uk.

## Files

- `bundesliga_2324.csv`
- `bundesliga_2425.csv`
- `bundesliga_2526.csv`
- `bundesliga_combined_raw.csv`

## Role in the Project

These files are used to build the market benchmark in `07_market_odds_benchmark.ipynb` and in [`../../../src/odds_processing.py`](../../../src/odds_processing.py).

## Note

Odds are not the primary target of the project, but they provide an important reference point for judging prediction quality and market alignment.
