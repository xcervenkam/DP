# next_matchday_predictions

This folder contains tables used for scoring the next Bundesliga matchday.

## Typical Outputs

- `deployment_registry.csv`
- `cutoff_summary.csv`
- `candidate_summary.csv`
- `selected_candidate_fixtures.csv`
- `all_next_predictions.csv`
- `prediction_failures.csv`

## Role in the Project

These tables are connected to `10_next_matchday_predictions.ipynb` and the deployment helpers. The folder links saved models to the currently available upcoming fixtures.
