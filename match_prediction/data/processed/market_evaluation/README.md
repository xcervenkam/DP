# market_evaluation

This folder contains tables used to compare saved models with the market benchmark.

## Typical Outputs

- `coverage_summary.csv`
- `classification_summary.csv`
- `probability_summary.csv`
- `probability_gap_summary.csv`
- `value_betting_summary.csv`
- `blanket_betting_summary.csv`
- `matchday_accuracy.csv`

## Role in the Project

These tables are mainly created in `08_market_evaluation.ipynb` and support the interpretation of whether the models provide useful information beyond the market.
