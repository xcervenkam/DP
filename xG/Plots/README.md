# Plots

This folder contains exported figures created in the `xG` section.

## Types of Outputs

- league-level comparisons of expected and actual metrics,
- time-series views of `xG` and `xGA` in selected leagues,
- figures used in the Leicester 2015/16 case study,
- team-profile and clustering visualizations,
- dendrograms for hierarchical clustering.

## How to Read This Folder

- File names correspond to themes covered in the main notebook.
- These figures are suitable for direct reuse in the written thesis.
- If new exports are added, it is useful to keep the same naming logic so the connection to the notebook remains clear.

## Examples

- `xpts_pts.png` compares points and expected points.
- `xG_xGA.png` shows the relationship between attacking and defensive expected quality.
- `dendrogram_epl_2015.png` and `dendrogram.png` support the interpretation of clustering results.
